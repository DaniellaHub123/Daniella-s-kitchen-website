
# Daniella's Kitchen Website

## 1. Project Description
Daniella's Kitchen is a restaurant website created using HTML and CSS. It provides information about the restaurant, its food menu, services, ordering process, and contact details.

The website is designed to help customers learn about the restaurant and easily navigate between its pages.

## 2. Technologies Used
- **HTML5:** Creates the structure and content of the website.
- **CSS3:** Controls the website's colours, fonts, layout, buttons, spacing, and responsive design.
- **No JavaScript:** The website does not require JavaScript. Navigation is handled using HTML links, and the design is controlled using CSS.

## 3. Website Pages

### Home Page — index.html
Displays the restaurant's welcome message, introduction, and navigation links.

### About Page — about.html
Provides information about the restaurant, its background, mission, and values.

### Menu Page — menu.html
Displays the available food items, descriptions, and prices.

### Services Page — services.html
Explains the services offered by the restaurant, such as dining, takeaway, and catering.

### Order Page — order.html
Provides an order request form where customers can enter their details and food preferences.

### Contact Page — contact.html
Provides contact information and a form for visitors who want to send a message.

## 4. CSS Styling — style.css
The style.css file controls the appearance of all website pages. It is responsible for:
- Background colours and text colours.
- Font styles and sizes.
- Navigation menus and buttons.
- Page layouts and spacing.
- Image sizes and presentation.
- Responsive layouts for different screen sizes.

## 5. How the Website Works
The website uses HTML links to move between its pages. Each page links to the CSS stylesheet to maintain a consistent design.

When a visitor clicks a navigation link, the browser opens the selected HTML page. The website can run directly in a browser without a JavaScript file or database.

## 6. How to Run the Website
1. Download and extract the project folder.
2. Open Visual Studio Code.
3. Select **File → Open Folder**.
4. Open the Daniella's Kitchen project folder.
5. Open index.html.
6. Right-click the file and select **Open with Live Server**, if the Live Server extension is installed. Alternatively, open index.html directly in a web browser.

## 7. How to Edit the Website
- Edit the HTML files to change headings, paragraphs, menu items, prices, and contact information.
- Edit style.css to change colours, fonts, backgrounds, spacing, and layouts.
- Save the files and refresh the browser to see the changes.

## 8. Limitations
The website is a front-end project. The order and contact forms are demonstration forms and do not automatically send information to the restaurant. To receive real orders or messages, a backend service or form-processing service must be connected.

## 9. Conclusion
Daniella's Kitchen demonstrates how HTML and CSS can be used to create a multi-page restaurant website. It provides organised information, consistent styling, and straightforward navigation without using JavaScript.
